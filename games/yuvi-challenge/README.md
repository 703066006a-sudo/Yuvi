# 挑战 YUVI

原创单人 Boss 挑战网页 Demo。直接用浏览器打开 dist/index.html 即可游玩，无依赖。

## 操作

- WASD / 点击地面：移动
- 点击 Boss / 空格：锁定攻击，射程内自动普攻
- Q：穿透飞刃，冷却 4 秒
- E：突进，0.45 秒无敌，冷却 4 秒
- R：范围爆发，冷却 12 秒
- Esc：暂停

## 挑战规则

Yuvi 18000 生命；玩家 560 生命，一次生命。Boss 在 65% 和 30% 血量进入新阶段，最终阶段每 1.4 秒生成一轮范围攻击。红圈预警后结算伤害，可用走位与突进躲避。通关率尚未进行真人实测。

## 文件

- dist/index.html：页面与界面
- dist/game.js：战斗、技能、AI、绘制
