# 挑战 YUVI · 简单直接的 Boss 战

选择英雄，开场直接挑战 12000 生命、三个阶段的 YUVI。没有金币、装备、兵线、蓝量消耗或升级。保留细化的原创 2D 场景、攻击特效与三种英雄。

## 玩法

- 鼠标点击地面或方向键移动；射程内自动普攻，点击 Boss 可追击
- Q：方向攻击；E：位移闪避，0.45 秒无敌；R：范围爆发
- 三个技能开场全部可用，只需等待冷却
- H：帮助；Esc：暂停；右上按钮可切换音效或进入全屏
- 一条生命，失败立即重开

游侠拥有三连箭，法师拥有减速法球，剑卫拥有高生命和冲锋眩晕。Yuvi 在 65% 和 30% 生命时强化攻击，释放红圈爆破和弹幕。实际通关率尚未进行真人测量。

## 运行

直接用浏览器打开 index.html。当前目录应包含 index.html、style.css 和 game.js。

本地完整项目的网页文件位于 dist/；可运行 `python3 -m http.server 8847 --directory dist` 预览。运行 `node tests/game.test.cjs` 检查 Boss 阶段、技能冷却、闪避无敌与胜负。

最佳成绩保存在当前浏览器本地，没有在线排行榜。旧版源码保留在 Git 历史中。
