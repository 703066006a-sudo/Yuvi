# TradingView 看图与绘图复刻研究

研究日期：2026-10-02。范围：看图、画图、回放工作台；本轮为资料研究，没有修改产品界面。

## 用户已确认的第一版规格

用户提供 TradingView 桌面截图，作为整体布局参考。复刻目标是整体布局接近，不要求所有菜单和功能逐项一致。截图中的标的是 ORCL；参考链接参数不是实际显示品种，品种与截图中的新闻、指标、买卖报价不自动纳入需求。

视觉基准：浅色主题；一条紧凑顶部工具栏；左侧窄绘图栏；中央大面积图表；右侧列表与详情的上下分区；右侧窄功能入口栏；底部时间范围与状态区域。浏览器标签栏和地址栏不属于产品界面。项目右侧使用现有复盘对象、笔记、成交信息承载对应分区；自选股、新闻、警报、真实下单、截图中的布林带不作为本轮新增功能。

第一版必备八种工具：趋势线、水平线、平行通道、斐波那契回撤、多头仓位、空头仓位、矩形、文字。现有其他工具可以保留，不扩张本轮开发范围。

行为要求：
- 回放按图形创建时间隐藏未来对象；编辑不保存历史版本。
- 锚点持久化保存原始时间和价格，不持久化屏幕坐标。
- 跨周期通过原始时间映射到目标周期时间桶及相邻可用 K 线位置；缺口规则须明确。仅渲染映射，不因切周期写回或修改原始锚点。
- 桌面优先，窄屏基本可用；完整手机适配单独做。
- 验收包括外观、操作和数据恢复。

实施默认细节（可在实现验证中调整）：斐波那契默认级别 0、0.236、0.382、0.5、0.618、0.786、1；双锚点支持反向绘制；显示价位和比例。右侧面板可折叠；绘图选中优先显示浮动编辑条，不自动展开面板。保存新增样式字段时必须向后兼容旧复盘数据。

验收清单：
1. 桌面布局对照用户截图，检查工具栏密度、图表占比、分区、浅色背景和坐标轴层级。
2. 八种工具逐项验证创建预览、取消、选择、锚点拖动、整体移动、样式编辑、锁定隐藏和删除。
3. 滚动、缩放、窗口缩放后图形对齐；跨周期往返不改变原始锚点；未来区间和缺口行为明确。
4. 一次拖动作为一个撤销步骤；撤销重做、保存刷新恢复结果一致；旧格式记录可读取。
5. 回退隐藏未来创建对象，编辑旧对象后回退仍展示当前编辑版本；未来成交和笔记继续遵守已有规则。
6. 窄屏可访问核心控制且无不可操作遮挡；输入框不触发回放或删除快捷键。

本节为后续实施依据；下方早期建议若与本节冲突，以本节为准。

## 界面设计方向

官方把界面划分为顶部工具栏、左侧绘图栏、中央图表及坐标轴，以及部分产品的右侧组件栏。右侧对象树和自选列表是 Trading Platform 的内置功能；本项目可自行实现类似面板。

建议沿用这套信息层级：
- 顶部：品种、周期、图表类型、指标、撤销重做、图表设置、保存。按任务分组，用细分隔线区分。
- 左侧：光标；线工具；通道；形状；注释；测量和多空仓位。每组显示常用工具，展开选择其他工具。
- 中央：K 线最大化，左上紧凑显示品种和 OHLC，右侧价格轴，底部时间轴；成交量独立区域或明确分区。
- 右侧：对象树和复盘笔记，可折叠；选中对象时展示操作，但不强制打开面板挤压图表。
- 回放：使用底部紧凑控制条放置选起点、后退、播放、前进、速度和进度。
- 选中绘图：在对象附近出现浮动工具条，提供颜色、线宽、线型、设置、锁定和删除。

以下为项目设计建议，不是从参考页面量出的参数：顶部约 44–48px，左栏约 48–52px，图标约 18–20px；右面板约 280–320px；深色底、低对比网格、细边框，蓝色表示选择状态，涨跌色只表达行情。最终尺寸需通过实际页面视觉核对确定。

## 绘图交互规格

工具必须贯穿完整操作流程，而不只是能画出来：选择工具 → 锚点预览 → 完成 → 悬停命中 → 选中 → 整体移动/拖动锚点 → 样式编辑 → 撤销/重做 → 保存恢复。

建议统一交互：
- 单点工具：水平线、水平射线、文字；双点工具：趋势线、矩形、测量；三点工具：平行通道。
- 绘制中显示预览，Esc 取消当前草稿；是否持续绘图作为单独开关。
- 锚点拖动调整几何，拖动线或区域整体平移；锁定后不允许移动。
- 细线使用约 6–8px 的屏幕命中容差，避免用户必须精确点中 1px 线条。
- 磁吸以屏幕距离挑选附近 K 线 OHLC，区分吸附开关与强度；不要只按价格最近无限吸附。
- 设置面板分成样式、坐标、可见性；允许精确输入价格和时间。
- 多空仓位提供入场、止损、止盈、宽度控制与风险收益标签；文字标签不能遮挡拖动点。
- 对象树与图上选中同步，支持重命名、显隐、锁定、删除；后续增加排序和分组。
- 一次完整拖动只产生一个撤销步骤；编辑文字时快捷键不能误触回放或删除。

官方绘图 API 区分单点、多点、屏幕固定对象，并提供对象 ID、事件及分组机制；这些是自建绘图数据模型可参考的概念，不可直接调用到 Lightweight Charts 上。

## 当前项目对照

已查看 components/replay-chart.tsx、components/replay-workspace.tsx、package.json 和 README。
现有基础：Lightweight Charts 5.2.1、SVG 绘图层、时间/价格锚点、水平线和射线、趋势线、通道、矩形、文字、测量、多空仓位、锚点拖动、吸附开关、颜色、虚线、锁定隐藏、绘图撤销重做、保存与回放时钟。

下一阶段重点（基于代码检查，不代表已经运行验证）：
1. UI：分组绘图菜单、悬停说明、工具激活态、选中对象浮动工具条、折叠面板。
2. 编辑：整体平移、稳定命中范围、精确坐标设置、线宽、填充透明度、右键菜单。
3. 看图：轴缩放、滚轮缩放中心、十字线读数、成交量和主图区域，逐项核对手感。
4. 扩展：斐波那契回撤、箭头、竖线、画笔、收藏工具与模板；不必第一版覆盖所有工具。
5. 性能：当前绘图层通过持续 requestAnimationFrame 触发 React 更新，需评估改为视口、尺寸、数据、拖动变化驱动，避免空闲重绘。

## 实现路线

建议继续使用现有 Lightweight Charts + 自建 UI/绘图层，方便保持回放时钟和未来数据隔离。官方说明 Lightweight Charts 是开源图表库，指标需自行实现；其插件系统可用于扩展绘图。它不是完整 TradingView 工作台。

Advanced Charts 带有更完整的工具界面，可作为另一条路线；实际接入前需核实获取资格和许可，不能默认已有库访问权。普通嵌入 Widget 的自定义能力更少，而且不能接入自己的数据，不适合本项目的自定义历史回放。

建议实施顺序：基础布局 → 核心绘图编辑闭环 → 看图手感和性能 → 扩展工具。验收至少包含：滚动/缩放后绘图仍对齐；切换周期锚点规则明确；拖动可一次撤销；保存恢复一致；回放未来绘图和成交不提前显示；输入框与快捷键互不干扰。
